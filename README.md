## 기술

### 아키텍처

- [펜싱 토큰(Fencing Token) — 락이 만료된 뒤 늦게 도착한 쓰기 막기](notes/tech/architecture/2026-11-12-fencing-token.md) · 2026-11-12  
  락을 내줄 때마다 이전보다 큰 번호를 함께 내주고, 쓰기를 받는 저장소가 이미 본 번호보다 작은 번호의 쓰기를 거절하게 해서, 락이 만료된 줄 모르는 옛 소유자의 쓰기를 막는 방법입니다.

### 과부하

- [캐시 스탬피드(Cache Stampede) — 만료 순간 몰리는 재계산 막기](notes/tech/overload/2026-11-10-cache-stampede.md) · 2026-11-10  
  캐시 항목이 만료되는 순간 많은 요청이 동시에 같은 값을 다시 계산하면서 DB 같은 공유 자원이 과부하에 빠지는 현상입니다. 도그파일링(dog-piling)이라고도 부릅니다.

### 장애 대응

- [복구 시간 목표 · 복구 시점 목표(RTO · RPO, Recovery Time · Point Objective) — 얼마나 빨리, 어디까지 되살릴지 정하기](notes/tech/incident-response/2026-11-16-rto-rpo.md) · 2026-11-16  
  장애가 났을 때 서비스를 몇 시간 안에 다시 열어야 하는지(RTO)와 장애 직전 몇 분어치 데이터까지 잃어도 되는지(RPO)를 미리 정해, 백업 주기 · 복제 구성 · 예비 서버 규모를 고르는 기준으로 삼는 두 값입니다.
