## 기술 소식

### 1. API 목킹 도구 Mock Service Worker(MSW, 브라우저와 Node.js 에서 네트워크 요청을 가로채 가짜 응답을 주는 테스트 라이브러리)가 v3.0 을 냈습니다.

`프론트` · 2026-11-26

MSW 가 v2.0 이후 약 3년 만에 메이저 버전인 v3.0 을 공개했습니다.

배포 형식이 ESM(ECMAScript Modules, 자바스크립트 표준 모듈 형식) 전용으로 바뀌었고, Node.js 18 · 20 지원을 끝내고 22 · 24 · 26 을 지원합니다.

전이 의존성을 줄여 패키지 크기가 416KB 에서 234KB 로 작아졌고, msw/http · msw/graphql · msw/sse · msw/ws 처럼 프로토콜별 진입점이 생겼습니다.

Node.js 에서는 가로채기 위치가 TCP · TLS 계층으로 내려가 SMTP 같은 소켓 기반 프로토콜도 가로챌 수 있고, GraphQL 구독도 지원합니다.

업그레이드 뒤 브라우저의 OPTIONS 사전 요청까지 가로채 테스트가 실패한다는 사례가 공개 토론에 올라와 있습니다.

> 확인할 점: 프론트 테스트에서 MSW 를 쓰는 프로젝트라면 Node.js 22 이상과 TypeScript 5.9 이상인지 확인하고, 마이그레이션 가이드대로 임포트 경로를 바꾼 뒤 CORS 사전 요청 테스트를 다시 돌려 봅니다.
