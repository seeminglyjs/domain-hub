## 도메인 소식

### 1. Databricks 가 Unity Catalog 지표 뷰를 Power BI 시맨틱 모델로 내보내는 기능을 비공개 프리뷰로 공개했습니다.

`제품` · 2026-11-10

Databricks(데이터 · AI 분석 플랫폼 회사)는 2026-11-10 Unity Catalog(Databricks 의 데이터 권한 · 메타데이터 관리 기능) 지표 뷰(Metric View, 지표를 한 번 정의해 여러 도구가 쓰게 하는 기능)를 Power BI(Microsoft 의 BI 도구)로 내보내는 'Publish to Power BI' 를 소개했습니다. 같은 지표를 Power BI 작업 공간마다 따로 정의하면서 숫자가 서로 어긋나는 문제를 줄이려는 것이 배경입니다.

이 기능은 지표 뷰 하나를 Power BI 시맨틱 모델의 표 하나로 만들고, 차원은 열로, 측정값은 DAX(Power BI 의 계산식 언어) 측정값으로 옮깁니다. 기본 방식인 DirectQuery(BI 도구가 원본에 매번 직접 조회하는 방식)에서는 모든 조회에 Unity Catalog 권한이 적용됩니다.

내보내기는 Databricks 에서 Power BI 로 한 방향뿐이어서, Power BI 에서 고친 측정값은 지표 뷰에 반영되지 않습니다. 현재 비공개 프리뷰(Private Preview, 신청한 고객에게만 여는 시험 단계)이며 계정 담당 팀을 통해 신청해야 합니다.

> 확인할 점: 지표 정의를 여러 BI 도구에 복사해 쓰고 있다면, 정의를 한 곳에 두고 도구 쪽 수정이 원본에 돌아가지 않는 한 방향 구조로 바꿀 수 있는지 검토합니다.

출처: [Databricks 블로그: Unity Catalog Metric Views, now in Power BI](https://www.databricks.com/blog/unity-catalog-metric-views-now-power-bi-one-unified-governed-semantic-layer-all-your-reporting)

## 기술 소식

### 1. Spring for Apache Pulsar 가 Apache 재단의 Pulsar 하위 프로젝트로 옮겨 가고, 2.0.8 이 Spring 아래 마지막 판이 됩니다.

`백엔드` · 2026-11-10

Spring 팀은 2026-11-10 Spring for Apache Pulsar(Spring 앱에서 분산 메시징 플랫폼 Apache Pulsar 를 쓰게 하는 라이브러리)를 Apache 소프트웨어 재단(ASF, 오픈소스 프로젝트를 관리하는 비영리 재단)의 Apache Pulsar 하위 프로젝트로 옮긴다고 발표했습니다. 새 이름은 'Apache Pulsar support for Spring' 이고, Pulsar 커뮤니티와 더 가깝게 개발하려는 것이 이유입니다.

Spring for Apache Pulsar 2.0.8 이 Spring 아래 마지막 판이며, Spring Boot 4.2.0 에서는 2.0.8 을 계속 쓸 수 있습니다. Spring Boot 의 Pulsar 스타터(starter, 의존성과 자동 설정을 묶은 패키지)는 더 이상 관리하지 않고, Spring Cloud Stream(메시지 브로커 연결을 추상화하는 Spring 프로젝트)의 Pulsar 바인더는 5.1.0 이 마지막입니다.

Spring 은 앞으로 이 프로젝트에 업데이트 · 패치 · 버그 수정을 내지 않고, 모든 유지보수는 Apache Pulsar 프로젝트가 맡습니다. 이후 수정을 받으려면 Pulsar 를 쓰는 Spring 앱은 의존성 좌표와 패키지 import 를 새 Apache 프로젝트 것으로 바꿔야 합니다.

> 확인할 점: Spring Boot 에서 Pulsar 스타터나 Spring Cloud Stream Pulsar 바인더를 쓰는지 확인하고, 업그레이드 계획에 새 Apache 좌표로 옮기는 작업을 넣습니다.

출처: [Spring 블로그: Announcing a New Home for Spring for Apache Pulsar](https://spring.io/blog/2026/11/10/spring-pulsar-new-home-asf)

### 2. 코드 실행 호스팅 서비스 Val Town 이 단계적 종료 일정을 발표했습니다.

`아키텍처·운영` · 2026-11-10

Val Town(웹에서 작은 TypeScript 함수를 써서 바로 실행 · 배포하는 호스팅 서비스)은 2026-11-10 서비스를 단계적으로 종료한다고 발표했습니다. 회사는 클라우드 컴퓨팅 시장에서 경쟁할 수 없었다는 것을 이유로 들었습니다.

발표 당일 신규 가입과 요금제 상향이 멈췄고, 12-10 에는 SQLite · blob 저장소를 제외한 서비스가 읽기 전용이 됩니다. 2027-01-10 에 나머지 서비스가 끝나고, 2027-02-01 에 Val Town 이 오픈소스로 공개됩니다.

요금 청구는 발표일부터 멈췄고, 연간 요금을 미리 낸 사용자는 일부를 돌려받습니다. 회사는 Cloudflare · Vercel · Netlify · Render 로 옮기는 안내서를 제공하지만, 글에는 데이터 내보내기 도구에 대한 설명이 없습니다.

> 확인할 점: 작은 외부 호스팅 서비스에 정기 작업이나 웹훅을 맡겨 두었다면, 서비스가 끝날 때 옮길 곳과 데이터를 내보내는 방법을 미리 적어 둡니다.
